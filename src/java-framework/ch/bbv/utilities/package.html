The utility package contains a set of utility methods used through the applications.

Purpose

The utility package contains a set of utility methods used through the applications. The functions are missing extensions to the standard libraries. Two areas of algorithms are identified.

First convenience methods for reflection functions. The reflection packages throw a lot of exceptions, which often do not interest the callers because it is guaranted that they never occur in a tested system. Second text manipulation routines to create identifiers following the coding guidelines of the Java language.
