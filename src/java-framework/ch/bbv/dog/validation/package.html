Introduction

Business object models needs to be validated against a set of business rules. The rules are defined as validation rules. The business object types being Java beans, the rules are connected to the model through the bean descriptor meta-model. All feature descriptors support set and get of named values.

Validation Types

Range Check
The property must be inside the defined range of values. All primitive types and their wrappers are supported.
Pattern Check
The string property value respects the defined regular expression. Minumum and maximum length of a text are also handled in this check.
is null
The property value is null.
is not null
The property value is not null.
are unique
All the values of an indexed property are unique.
are null
All the values of an indexed property are null.
are not null
All the values of an indexed property are not null.

Conventions

The values are identified through names. Conventions must be defined to find out where validation rules are stored in the descriptors.

  • The validations rules of a property are defined as a set of rules. They are stored in the property descriptor. The set is stored under the name "validation".
  • The validations rules of a bean are defined as a set of rules. They are stored in the bean descriptor. The set is stored under the name "validation".
