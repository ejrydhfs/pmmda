Introduction

The business object graph package defines a framework to manipulate complete graphs of business objects either in standalone applications or in client server configurations.

The concepts how to manipulate graphs of value transfer objects are described in the article Business Object Graphs and Business Object Derived Attributes.

Business Objects

Business objects are abstractions defined concepts of the application domain for which the application was created.

Reference Codes

Reference codes implements application domain enumeration types. For example the worldwide currency classification of the ISO standard defined such an enumeration. Each enumeration should be implemented in a seperate reference code class to insure type integrity checks at compile time. The identifiers of a reference code set should be declared as enumeration types.

Decisions
