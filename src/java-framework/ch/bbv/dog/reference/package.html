Introduction

Reference code types are the business model equivalent of enumerations. The set of values for a type is defined. Each type has an identifier, a time interval when it is active, a short description and a description.

The package provides a reference implementation of regular and hierarchical reference codes and a scalable management infrastructure for distributed client server applications. A reference code value is active during a time interval and after is available as inactive code. Retrievers are provided to get set of values for a reference code type from various persistence stores.
