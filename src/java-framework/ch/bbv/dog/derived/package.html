Functions computing derived attributes can be associated with the update of a property. Mechanisms are provided to implement these services.

Introduction

The package provides functions which can be associated with the update of a property. Each time the property is modified the function is applied and synchronize the values of derived attributes. The functor is associated with a business object type and a property change event.

The chosen solution heavily uses services provided in the standard Java beans package. This approach that application programers find a well-known and optimally documented approach. The patterns of use are very similar to the ones used in other Java bean oriented approaches.

The decision when to register a set of business objects and starts to compute derived properties is taken in the domain application and not in the framework. Various derived attributes computation strategies can be implemented in the application.
