The service package provides a framework to integrate external services in an application.

Purpose

The service package provides a framework to integrate external services in an application. Complex business operations often require services from external systems. A well defined sequence of calls must be performed to realise a step in the company workflow. The framework provides mechanisms simplifying the implementation of such a chain. The application programmer does not anymore need to write repetitive code to call external systems.

@since Java 2 Platform, Standard Edition, version 1.4
