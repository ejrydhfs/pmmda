The kernel package is the Java implementation of realtime services used to develop complex embedded applications.

Purpose

The kernel package is the Java implementation of realtime services used to develop complex embedded applications. The services are similar to the ones developed for a portable open source layer written in C/C++ and hiding the pariticularites of a set of commercial and open source embedded kernels.

Upon availability of JDK 1.5 and the concurrent package, the kernel package was adapted to integrate smoothly with the provided services.

Architecture

State Machine

State machines are provided through the State Map Compiler SMC open source project. The project is hosted on Sourceforge under the address @see SMC home page.

The state machine framework previously developed and used was discarded. The SMC framework provides similar capabilities - but without the support of hierarchical machines also called Harel statecharts -. The development and documentation tools are well developed. For example state machines can be debugged or graphical representations generated.
