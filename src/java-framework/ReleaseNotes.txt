Version 0.2.1-RC2 (30 October 2004)
-----------------------------------
The following new features were added.
- The generic properties node dialog was enhanced to support edition of their
  values based on their types. Date fields are displayed with a powerful open
  source calendar bean. 
- The creation of popup menus for nodes is now delegated to a factory. Now
  it is a lot easier to extend the framework with its own popup menus. The
  mechanism is similar to the icon factory. No new paradigm needs to be 
  learned.  
- A status bar was added to the explorer. Initial support is provided for
  status and progress information.

The following errors were corrected.
- Wrong error message was displayed in revert and reload actions.
- Boolean values are handled in sortable table as Swing does it. Boolean values
  are displayed with checked boxes. The table cell class was refactored and
  redundant code was removed.
- The handling of node type in the UI node type factory had an error. The 
  returned view was erroneous if the view class is a parametric one used in
  multiple node type. The selection algorithm was modified to support such 
  classes.
- The Swing user interface creation pattern is now used to execute the explorer
  in the context of the AWT event processing thread.
- The source code was refactored to support the for pattern when using an 
  iterator.
- The tree construction functor had a missing functionality. It was not possible
  to retrieve an explorer node based on the identifier of its lightweight or
  data object. Therefore the behavior of open view generated a null pointer
  exception the first time it was called.
- The signature of the lightweight object interface was modified to allow an
  object to implement data object and lightweight object interfaces. At least
  one application we know displays the same object in the navigator and in the
  right pane.

Version 0.2.1-RC1 (30 September 2004)
-------------------------------------
The following new features were added.
- Validation framework is completed and an initial test application uses it.
- The minor release of glazed lists 0.9.2 is integrated. 
- Caching for client explorer applications are supported.
- The node actions expand all and collapse all were introduced.

The following errors were corrected.
- Refactoring of all node actions streamlined their implementation.
- The persistent store operation now handles correctly newly created graph. In
  this case the method should not try to retrieve the old graph from the 
  persistent store.
- The remove operation using an identifier now correctly flushes the cache in 
  the cache handler.
- The handling of identities in the collect functors was wrong when two 
  copies were compared.
  

Version 0.2.0 (30 June 2004)
----------------------------
The following new features were added.
- The CVS repository was moved to the sourceforge pmmda account.
- The new major release of glazed lists 0.9.1 is integrated. The table handling
  is simplified and all columns are sortable.
- The persistence algorithm was optimized. Only one traversal of the tree
  to update is now needed instead of two.
- The terminology "data object" of JSR-235 is now used to name the business
  object. The JavaDoc documentation was 
- Support of OJB in managed environment such as J2EE containers - tested with
  JBoss and WebSphere -. 
- Integration of the lock handler in the CORBA and J2EE servers. The current
  implementation does not support clustered environments.
- The explorer about package is now based on the glazed list package.

The following errors were corrected.
- The JavaDoc comments were enhanced.
- Error in the event propagation when a node was removed from the navigation
  tree was corrected. Removal of children through context sensitive menu works.
- The post-store visitor did not set the modified flag back to false. Therefore
  too many updates were performed.
