Project Structure
-----------------

The following subprojects are defined.
  - pmMDA: "poor man MDA" is a MDA application with code generators based on 
    the Velocity engine. The supported platforms are 2 tiers, CORBA and J2EE.
  - BOG: "Business Object Graph" is a framework used to manipulate business
    object models defined as graphs of connected objects. These graphs are
    sent as DTO between the client and server application.
  - Explorer: is a framework used to visualize and edit business object
    model through a user interface. The user interface uses the tree list
    paradigm.
  - Documentor: are a set of extension for the documentation of the source
    code of the application.
