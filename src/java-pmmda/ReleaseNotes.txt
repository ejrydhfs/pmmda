Test Support
------------
The pmMDA provides a set of tests used for regression each time a new version
is released. The tests are provided a set of UML models and associated java
classes. The classes are stored in the test tree of the project.

Version 0.3.0-RC2 (25 December 2005)
------------------------------------
The following new features were added.
- Moved the newest JDK 1.5.0-06 to check compatibility.
- The OJB cartridge has a new property controlling if constraints are generated
  when foreign keys are defined in the DDL.
- The cartridge default implementation was extended to support a declarative 
	approach for the definition of stereotypes, tags and properties. Therefore 
	architects can tailor the default values of tags for their application 
	domain.
- Glazedlists package was updated to version 1.0. All Jakarta commons packages
  are updated to the newest stable version.

The following errors were corrected.
- The java class 1.5 template for the bo cartridge had an error in the handling
  of the navigable property.
- The handling of navigable relations had an error if the name of the property
  used for backward navigation started with a lower case.  
- In special cases the getter name was eroneously defined following the conventions
  of boolean properties. This error is corrected.  
- The NSUML writer had a type cast error when retrieving associations. The cast
  is now set to classifier instead of class.
- The import statements for all Java related cartridges were improved to diminish
  the warnings issued in Eclipse.
- The persistence flag is now defined as an UML tag and defined in the persistence
  cartridge.  
- Typos were corrected in the validation messages.

The following errors and change requests are closed 
  Errors: 1271421, 1271409, 1380522, 1379485, 1376242, 1285910 
  CR: 1305596, 1382323
  (see Sourceforge site RFE and Tracker for detailed description)

Version 0.3.0-dev (15 June 2005)
------------------------------------
The following new features were added.
- A document was introduced at the level of the MDA explorer to provide
  an extension mechanism to store PIM or PSM information outside the XMI
  model. This decision is due to the extensibility limitations of UML.
- The initial version of reference code values definition application is 
  integrated in the pmMDA application. The values are not stored in the UML
  model because such usage are not foreseen in the OMG meta model.
- Protected code zones for imports, constructors, declaration and definition
  are available for Java source code artifacts either for business objects or
  reference codes.
- Upgraded jgraph and jgraph add ons librairies to the newest versions 5.4.5 
  and 1.0.7. The upgrade eliminates errors in the jgraph packages.
- Updated glazedlist libraries to the newest version.
- First feedback from Technical University of Raperswil was added to the trunk.
- The source code was refactored to support the features of JDK 5.0.
- Inheritance support was added to the OJB cartridge and templates.
- All Java templates were extended to support Java 1.4 and 5.0. The type
  checking is more stringent due to the generics features. The property file 
  is extended to support the new option.
- The command line interpreter library from Jakara commons is now used to parse
  the command line of the application and the provided examples. The help
  message and flexibility is increased.  

The following errors were corrected.
- The user interface global actions were refactored.
- The javaDocComment was renamed to docComment and JavaDoc documentation 
  conventions were removed to simplify support of over programming languages.
  The algorithm was improved to support user defined formatting.
- Added extended support for navigability in the data object graph cartridge.
  Previously the concept was not supported in the cartridge templates.
- If a class is a lightweight one when its descendants are also lightweight
  because they inherit lightweight properties. This propagation rule was 
  missing.
- Generic properties view had an error when loading an empty object.
- Version identifiers are now provided for all serializable classes to insure
  compatibility between minor versions of the application. This compatibility
  is expected from the versioning scheme.
- Serialize patterns insure initialization of transient property and uniqueness
  of singleton instances. The new XStream library uses the JDK foreseen hooks to
  implement them. The JavaDoc documentation was extended to support serial tag
  information.
- Documentation errors in the description of attributes in the DOG cartridge are
  corrected - the container and key classes in the attributes are component names
  and not qualified names as in the corresponding tag values -.  

The following errors and change requests are closed 
  Errors: 1021167, 1029885, 1085670, 1105202, 1105446, 1105974, 1105978, 
  1106795, 119390
  CR: 1197387, 1197388
  (see Sourceforge site RFE and Tracker for detailed description)
  
Version 0.2.9-RC2 (30 October 2004)
-----------------------------------
The following new features were added.
- The naming conventions for tags and the persistence tags were aligned to the
  terminology of the UML standard version 1.5.
- The OJB cartridge was extended to support generation of indexes for all 
  foreign keys. This feature is controlled through a property. This option
  simplifies the generation of referential integrity rules.
- Macros for Velocity template are enabled. The templates were refactored to 
  use macros. The code is now more error resilient. Various inconsistencies
  were corrected.
- Added a minimal memory usage meter available to the developers of the 
  application or cartridges. In the future we will probably use the features
  provided with JMX in JDK 5.0.
- Build files based on Ant were refactored to support new version of forrest
  and simplify the structure. All tasks can now be called from build.xml. The
  minimal version of Ant is 1.6.
- The project team started to use JMX extensions and JConsole to monitor the 
  application.

The following errors were corrected.
- Error in the generation of the DDL for MySQL for 1-1 relationships.
- Modified the templates to implement the new interface signature of lightweight
  object.
- Insures that the copy operation sets the modified flag to the value of the 
  copied object.

Version 0.2.8 (30 June 2004)
---------------------------
The following new features were added.
- pmMDA is now available as a sourceforge project. The source code and all
  artifacts are available under license Apache 2.0 at sourceforge under
  www.sourceforge.net/projects/pmmda.
- Release notes for future versions of the BOG framework will be handled in
  the BOG release notes.
- The BOG cartridge was optimized not to generate superfluous import 
  statements.
- The velocity engine was upgraded to version 1.4.
- The XML persistency layer moved from the betwixt to the xstream library.
  The Jakarta Commons Betwixt project is dead. JAXB is not an alternative
  for our project because JAXB wants control of the bean generation.
- The PMD rules were modified to allow identifiers with a length [3..20]. 
- The Ant file was updated to be more usable when used on machines with 
  different file structures from the one on our development machines.
- The cartridge properties were extended to allow simultaneous generation of
  rich client interfaces using direct access, CORBA and J2EE middleware to
  communicate with the database.

The following errors were corrected.
- Obsolete tagged values defined in earlier versions of cartridges are now
  correctly removed from a model when saved. Obsolete tag types must be 
  registered in the retrieve obsolete tag types.
- The cartridge factory is now resilient to spaces at start and end of 
  cartridge names defined in a property file.
- Import statements for standard classes not defined in the ArgoUML model are
  now handled without generating an exception. A error message is added in the
  log file if a non Java standard class is used but not defined in the model.
- The visitor template does not generate visit method for referenced business
  objects classes defined in another package. The user can define such cross-
  package dependencies by hand in his execute method.
- Corrected an error in the generated XML deployment descriptors for J2EE. The
  DTD reference had a typo.

Version 0.2.6 (04 April 2004)
-----------------------------
This version is the first one where most of the work was performed in the
cartridge and not in the kernel of the pmMDA.

The following new features were added.
- All cartridges are now loaded dynamically through the extension mechanism.
  The only requirement is that cartridges implement the cartridge interface.
- The CTO cartridge was extended to generate complete CORBA server and wrappers
  for the business object graph framework. The retrieve and update operations
  are available for all defined business object graphs.
- The OEX cartridge templates were enhanced to minimize the code the client
  programmer has to write. 
- The lightweight template and the OEX cartridge do not request anymore a name
  property. A new tagged value defines the property used to generate the name
  of a node.
- The properties were extended and the cartridges adapted to enable users to
  generate common, server, and client code in different repositories.
- The OJB cartridge was extended to support the definition of reference code
  values and the generation of more complex reference code Java classes.
- The test application was extended to test more extensively the cartridges.

The following errors were corrected.
- The import statements support handles the type used in the properties. This 
  was a regression of the 0.1 series developed during Spring 2003. The 
  statements are sorted.
- The OJB cartridge templates had an error when generating backward relations
  for business objects and generated too many relations in the special case
  where the business object type of a N relation is persistent but not 
  lightweight.
- The OEX framework now expands the tree up to the selected node when the 
  business object below is loaded.

Version 0.2.5 (10 March 2004) - Internal Release -
--------------------------------------------------
The following new features were added.
- The pmMDA was extended to support pluggable cartridges. Now you can add a new
  cartridge without modifying or recompiling the pmMDA application. Initial
  input of the HSR Rapperswil semester project is integrated in this release.
- The next iteration of the OEX cartridge and the associated explorer framework
  was performed. The example used to test BOG and OJB cartridges is also used 
  to test OEX cartridge. Documentation was extended to present the OEX concepts.
- The OJB cartridge and the BOG framework are more extensively tested with the
  User test and MySQL database.
- The BOG cartridge was extended to provide visitor for the lightweight 
  objects. This feature provides orthogonal functionality to the business object
  graph framework.

The following errors were corrected.
- An error in the pre-processing of dependants cartridges was corrected.
- Non used code was removed from the velocity template to make them more 
  legible. The OJB templates were extended to support anonymous foreign keys.
  The template of the visitor was extended to support a depth information - see
  the pmMDA documentation for the reasons -.
- Layout correction in the tagged value list providing better display of combo-
  box.
- Removal of singleton pattern in the user interface node type factory to 
  provide more flexible option. Each explorer instance has now its own factory.
  An error was removed in the generation of the popup menus.
- System packages and classes are no more extended with tagged values defined 
  in the cartridge. These classes cannot be generated and should not be handled
  in the cartridge framework.
- The generation of setter in the Java beans had an error in the test if the
  property changed.

Version 0.2.4 (22 February 2004)
--------------------------------
The following new features were added.
- A major upgrade of the explorer framework was made available. A new cartridge
  OEX was added to support the generation of simple user interface based on the
  explorer tree list paradigm. The JGoodies layout managers are integrated in 
  the explorer framework to enhance look and feel. The new framework was used 
  to refactor all dialogs of the pmMDA. Reference codes can be displayed as
  field value or as tagged value.
- The OJB cartridge was extended and has now a Torque target. The generated
  Torque file can be used to create database for all database products 
  supported in Torque. The goal was added to help teams already using Torque.
- The source code copyright was updated from the Apache license 1.1 to version
  2.0.
- Build scripts were updated to Ant 1.6. You must use Ant 1.6 or higher to
  sucessfully build the project.
- A test example managing user accounts for a web application is provided.
  The example is compatible with the JDBC realm of Tomcat 5.
- The properties "ojb-jdbc-type", "ojb-jdbc-size", "ojb-jdbcType" and 
  "ojb-jdbcSize" are now obsolete and replaced by "ojb-column-type" and 
  "ojb-column-size". Obsolete properties are automatically removed when
  the model is loaded. These properties will be deprecated in the next release.
- Installation notes and support for execution of the pmMDA without eclipse
  are now provided. The properties file of pmMDA now contains documentation
  about major configuration options.
- The user management example shows the capabilities of the various cartridges.
- Shell scripts are provided to start pmMDA as a standalone application.

The following errors were corrected.
- Tagged values in the view mode cannot anymore be edited in the dialog. This
  behavior is coherant with the fact it is no possible to modify a view dialog.
- The installation nodes were extended to clearly describe how to start the 
  application outside and inside Eclipse. More information how to write a 
  compliant ArgoUML model were added to the FAQ part.
- Handling of aggregation and composition relationship now contain description
  and UML standard tags. The synchronization works in both directions.
- The types of the cartridges tagged values are documented in more details. 
  This modification was performed upon request of students doing a semester
  work with pmMDA.
- Testing and debugging are performed with assertion enabled to increase error
  detection against robustness. Deployment is done without enabling assertions.
  JDK 1.4 or higher is required.

Version 0.2.0 (15 October 2003)
-------------------------------
The version is based on the initial prototype used to create an Internet based
application, which managed network of connected devices. In particular the
explorer, application and command line parser packages were defined in this
project. The code generation and persistence packages were defined in private
projects. Ideas were developed during a big contract management project for 
an insurance company.
- The pmMDA has a complete model for project, package, class, property and 
  indexed property. The models can be saved in a serializable form. The 
  model handles dynamic addition of tagged values when additional cartridges
  are added.
- The business object cartridge generates Java code for the business objects,
  their lightweight representation, the visitor pattern and visitor functor 
  template, and the reference code manager. Support classes for the generated 
  source code are available with documentation.
- The persistency cartridge generates O/R mapping between the business object
  model and the persistency layer. The cartridge currently maps the model
  to the OJB 1.0 persistency framework.
- The pmMDA has a minimal explorer based user interface to edit MDA models.
