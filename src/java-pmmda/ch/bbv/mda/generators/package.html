The package provides various code generators to transform MDA models into executable code.

Introduction

The code generators are responsible to transform a MDA model or a part of it into executable source code. The generated code should be documented and legible. Code generators implement the cartridge interface and are accessible through the cartridge factory. This architecture is extensible. New cartridge implementations can easily be added to the factory and be called from client applications.

The design of the package assumes that all related busines object classes are members of the same package. This assumption follow the object-oriented design rules.

Analysis

Tag Initialization

Cartridges should initialize the tags they define. Two mechanisms are provided. A default value can be defined for a tag and will be automatically set upon creation. A listener mechanism is provided to enpower cartridge to perform more complex initialization.

Cartridge Checks

Cartridges should perform sanity checks to insure that configuration errors do not hinder the sucess of artifacts generation. The framework insures all necessary cartridges are available.

All cartridge properties have reasonable default values used when the user does not define specific values. These properties can be inspected in the user interface. So the user has a visual feedback about the configuration of the cartridges he uses.

Potential sources of errors are properties defining paths to non existing directories. Such errors provoke a runtime error and are difficult to trace. Therefore the cartridge interface provides a method to verify the existence of all defined paths.

Validation of Stereotypes and Tags

The generator framework provides hooks to validate the tagged values and stereotypes a cartrdige needs. The tag rule class provides a structure to define validation checks for a cartridge. Before a cartridge is asked to generate artifacts, its validation will be first executed.

Cartridge Description

Cartridges provide extensive information about their capabilities and actual configuration.

Architecture

Cartridge Implementation
