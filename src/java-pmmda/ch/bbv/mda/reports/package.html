Introduction

The pmMDA application provides a set of standard reports. They can be used to document a model, its stereotypes and all tagged values.

Reports

The reports provide criteria to select the subset of classes which should be included in the reports.

  • The list of packages which should be generated.
  • The list of stereotypes which are relevant. A class is part of the report only if it implements one of the listed stereotypes.
  • The list of cartridges which tagged values should be documented. The tagged values are identified through their prefix.

Each package contains the set of relevant classes with their properties and associated tagged values.

Design

The report engine is based on the open source Jasper report. A indirect evaluation was performed to select the reporting library. Major projects and references have a preference for Jasper reports.
