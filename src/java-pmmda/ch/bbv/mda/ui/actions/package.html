The package defines the specific actions for the MDA user interface.

Introduction

The actions specific to the MDA user interface are defined in the package. All cartridge generators related actions are defined here.

File Manipulation Actions

The application opens, saves and saves as files containing domain models. The supported extensions and their displayed names should be the same to provide a coherent user interface. These extensions and their names are defined in a utility class accessible to all action instances.

File Extensions

File extension support is provided through the classes simple file filter and file types. An application can define a set of extensions it supports. The following features are provided.

  • Each supported set of extensions is defined in a simple file filter instance. A filter can handle one or more extensions. The open and save as file selection dialog use these filters to select the files of interest
  • Each filter can define a default extension. If the user write a filename without extension this default extension can be appended.
  • A default extension can be defined for the application and is used if the user do not specify a filter.
  • Methods are provided to normalize file names and add the expected extension

The application is free to either add an default extension if the filename is missing an extension or provide an error message.
