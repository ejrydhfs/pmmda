Cartridge XML Description

The capabilities of a cartridge are described in a XML file and read in the framework when the cartridge is loaded. The following information can be configured.

Stereotype
Each stereotype can be described with the name, the context where it is used and a description.
Tag
Each tag of the cartridge can be described with the name, the type and default value of the tag, the context where it is used, and a description.
Obsolete Tag
Each tag once defined in the cartridge and no more used can be described to allow the framework to remove them from older models. The obsolete tag can be described with the name, the type and default value of the tag, the context where it is used.
Property
Each property of the cartridge can be described with its name and default value. This mechanism provides a default value for properites not defined in the application property file read at startup time.
Datatype
Each datatype defined in a model can be mapped to an implementation type used in the cartridge. The datatype has the name used in the model and the mapping type. A concrete class allows the definition of an interface and a concrete implementation class.

The context of an element can be package, class, property or indexed-property.
