Setting up CVS

The following steps allows you to setup a CVS repository.

  1. Make a backup of the whole project.
  2. CVSROOT /cygdrive/d/cvs; export CVSROOT in .bashrc
  3. cvs -d /cygdrive/d/cvs init to create the repository.
  4. cvs import -m "Initial import in CVS" ${PMMDA_HOME}/src pmMDA 0.0
  5. Remove all files under ${PMMDA_HOME}/src directory.

Now you can directly access the CVS repository using the built-in client of Eclipse.

Releases

Each internal and external release of the pmMDA must be tagged.

  1. Check-in all the files upon sucessful compilation, unit testing and sanity test.
  2. cvs tag tagname ${PMMDA_HOME}/src
