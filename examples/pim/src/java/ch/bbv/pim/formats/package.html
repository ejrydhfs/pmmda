Introduction

The package contains the transformation engines to the various supported formats. Two classes of transformation engines are defined. Emitters generates a given format, parsers parses a given format and stores the extracted information in the internal representation.

Standards

The VCARD standard is specified in RFC 2426. The MIME formats used inside is specified in RFC 2425.

The LDIF standard is specified in RFC 2849.

Rules

The transformation engines implements the following semantic rules.

  • The contact unique identifier is the LDIF distinguised name containing the full name and the email addresss. The VCARD formated name is used in the VCARD and contains the full name and the email address between rectangular parenthesises.
  • The first email address in the LDIF format is the business email address. The second email address is the private email address. Both addresses are optional.
  • The business email address is set as the preferred one in VCARD format.

Journal Entries

Journal entries document activities associated with a specific contact. The entries are specified as XML items to simplify the parsing and increase the interoperability between applications.

date
The date of the journal entry using the ISO date standard. The time is optional and should only be specified for meetings.
type
The type of the journal entry. The legal values are specified as a reference code: meeting, note, email.
author
The author of the journal entry.
duration
The duration of the journal entry activity.
