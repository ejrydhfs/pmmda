Introduction

The PIM application was developed to provide personal information management capabilities to users who are not always connected to the company Intranet. The application provides key functions in three areas.

The first group of functions provide interoperability to well known applications. Synchronization is provided with the Mozilla application suite in particular with Thunderbird contact management module. The exchange uses the LDIF format. Synchronization is also provided to any applications able to handle the Internet standard VCARD. IN particular the iPod devices can read this format and display it.

The second group of functions provide support for journal entries for all interactions done with a specific contact. These activities are coordinated with the information stored in external systems such as Thunderbird or VCARD based systems.

Usage

The application provides a command line to automate the transformation of a LIDF contact list into a VCARD list. The supported options are as follow.

-i[mport] <name>
the name of the file containing the contacts to import.
-e[xport] <name>
the name of the file where the exported contacts will be written.
-l[anguage] <language>
the language to use as default if none is specified in the contact. The parameter is optional. The default is English. Users can specify the default language they are working with.
-c[ountry] <country>
the country to use as default if none is specified in the contact. The parameter is option. The default is Switzerland. Users can specify the countrz they are working.

The following extensions are supported and the expected parser or emitter is automatically activated.

ldif
identifies files containing LDIF records.
vcard
identifies files containing VCARD 3.0 records.
pm.txt
identifies files containing Project Managertab seperated records.

User Interface

The user interface of the PIM application uses the explorer framework with dockable views of the pmMDA project.

The file menu supports the following actions.

New
Creates a new address book.
Open
Opens an open dialog. Upon selection of the name and the extension the correct format is used to read the address book.
Save
Saves the address book. The item is only active if an address book exists and was modified.
Save As
Opens a save dialog. Upon selection of the name and the extension the correct format is used to save the address book. If the extension is unknown an error message is displayed. The item is only active if an address book exists.
Exit
Quits the application. If an address book is opened and unmodified a dialog box asks if the changes should be saved.

Dialogs

Relocate Contact

The dialog provides functions to relocate contacts to another company. A left pane displays the list of all organizations. A right pane display the selected organization and its contacts. Between controls are provided to select the organization and relocate a selected to contact to the active organization. The operations are applied on the model during the interaction in the dialog. No cancel operation is provided.
