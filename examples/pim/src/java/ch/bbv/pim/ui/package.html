Introduction

The PIM application was developed to provide personal information management capabilities to users who are not always connected to the company Intranet. The application provides key functions in three areas.

The first group of functions provide interoperability to well known applications. Synchronization is provided with the Mozilla application suite in particular with Thunderbird contact management module. The exchange uses the LDIF format. Synchronization is also provided to any applications able to handle the Internet standard VCARD. IN particular the iPod devices can read this format and display it.

The second group of functions provide support for journal entries for all interactions done with a specific contact. These activities are coordinated with the information stored in external systems such as Thunderbird or VCARD based systems.

Usage

The application provides a command line to automate the transformation of a LIDF contact list into a VCARD list. The supported options are as follow.

-i[mport] <name>
the name of the file containing the contacts to import.
-e[xport] <name>
the name of the file where the exported contacts will be written.
-l[anguage] <language>
the language to use as default if none is specified in the contact. The parameter is optional. The default is English. Users can specify the default language they are working with.
-c[ountry] <country>
the country to use as default if none is specified in the contact. The parameter is option. The default is Switzerland. Users can specify the countrz they are working.
